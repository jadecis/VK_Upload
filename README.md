# Загрузка видео в VK

Скрипт пакетно загружает локальные MP4-файлы в сообщество VK, используя имя файла как название видео.

**Стек:** Python, vk_api.

## Устройство проекта

- `vk_downloader/main.py` — точка входа.


## Локальная настройка

В репозитории нет `requirements.txt`: состав зависимостей нужно восстановить по импортам перед запуском. Это ограничение воспроизводимости текущей версии.

В `vk_downloader/config.py` задайте собственные `token` и `group_id`. Замените локальный путь в функции `main()` на свою папку с MP4. Запуск отправляет видео в указанное сообщество.

После настройки зависимостей и конфигурации запускайте из корня репозитория:

```bash
python vk_downloader/main.py
```

Исходный проект для изучения интеграций и автоматизации. Запуск внешних сервисов и production-готовность этой версии не подтверждены.
